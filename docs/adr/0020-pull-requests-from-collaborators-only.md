# Pull requests from collaborators only

This repository takes no outside contributions. Pull requests come from collaborators' branches of this
repository, and from Renovate. Forks are out of scope for every feature: nothing is designed or kept working for
them, and a pull request from a fork fails its checks.

## Considered Options

- Forks build and test without publishing (the previous behaviour, never recorded as an ADR).
- A separate, reduced path for forks in each feature.
